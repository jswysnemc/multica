# 任务编排引擎核心实现

## 文件说明

- `workflow_engine.py`：内存版 DAG 工作流引擎，包含 DAG 构建、依赖校验、环检测、任务领取、状态机、失败策略和并发限制。
- `test_workflow_engine.py`：标准库 `unittest` 测试用例，覆盖题目要求的线性依赖、并行执行、菱形依赖、循环依赖检测、三种失败策略和并发限制。

## 运行方式

在项目根目录执行：

```bash
python3 -m unittest discover -s submission/task2/src -p 'test_*.py'
```

## 设计边界

该实现聚焦核心调度逻辑，使用内存数据结构模拟数据库。真实生产实现需要将任务状态转移、依赖完成计数和领取动作放入数据库事务，并通过行锁或乐观版本号保证并发安全。
