# Project Instructions

## Architecture

- Server state belongs to query cache or backend persistence.
- Client-only UI state belongs to local stores.
- Shared packages must keep dependency direction explicit.

## Workflow

- Read project instructions before code changes.
- Locate relevant files with semantic search first.
- Confirm exact code paths and line numbers with targeted file reads.
- Make the smallest coherent change.
- Run focused tests before broader verification.

## Code Rules

- Keep comments factual and implementation-focused.
- Do not add attribution footers or generated-content notices.
- Do not commit secrets.
- Prefer existing abstractions over parallel implementations.
